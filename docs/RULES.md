# 점검 규칙표 (검토용)

`data/rules.json`을 사람이 읽기 쉽게 풀어 쓴 문서입니다. 기준은 **2026 학교생활기록부 기재요령(중학교·고등학교, 교육부)**과 **2026 학교생활기록부 기재요령(초등학교, 충청북도교육청 유초등교육과 배포)**이고, 2026 학생부 현장점검에서 자주 나온 오류를 점검 항목에 반영했습니다.

심각도는 세 가지입니다.

| 표시 | 뜻 |
|---|---|
| 금지 | 기재요령상 기재할 수 없는 내용. 반드시 고쳐야 함 |
| 형식 | 표기 방식이 기재요령과 다름. 고치는 것이 원칙 |
| 확인 | 문제일 수도 아닐 수도 있음. 선생님이 직접 판단 |

## 2. AI 사용 흔적 (기재요령 II. 5-다)

| 항목 | 심각도 | 예 |
|---|---|---|
| 학생 지칭 | 확인 | 위 학생은, 이 학생은, 본 학생은, 해당 학생은 |
| 서식 기호 | 형식 | `**굵게**`, `##`, 줄 앞 `-`·`•` |
| 명사형이 아닌 종결 | 형식 | ~하였다. ~할 수 있다. ~했어요. → ~함. ~임. ~음. |

## 3. 표기 형식

| 항목 | 심각도 | 올바른 예 | 잡는 오류 |
|---|---|---|---|
| 일자 | 형식 | 2026.03.04. | 끝 온점 누락, 2026.3.4., 2026-03-04, 2026년 3월 4일 |
| 기간 | 형식 | 2026.03.04.-2026.07.08. | 물결표(~), 하이픈 중복(--), 하이픈 앞뒤 띄어쓰기 |
| 특수문자·번호 | 확인 | — | ①, ■, ▶, ※, 줄 앞 "1." |
| 영문 | 확인 | AI, SNS, PPT, UCC, TV, PAPS … | 허용 목록·고유명사 외 영문 |

## 4. 영역별 점검

| 영역 | 점검 | 심각도 |
|---|---|---|
| 모든 서술형 | 나이스 바이트 기준 글자수 초과 (한글 3, 영문·숫자·엔터 1) | 형식 |
| 출결 | 기타결석 사유 뒤 '(3일)' 표기, 출결 표 일수와 특기사항 일수 합 일치 | 형식 |
| 출결 | 출석인정결석 사유 입력, 질병명 기재 | 확인 |
| 창체 자율·자치 | 임원(회장·반장 등) 재임 기간 병기, 학년말 2027.02.28. | 형식 |
| 세특 | 같은 과목 학생 간 동일(95% 이상)·유사(70% 이상) 기재 | 확인 |

## 초등학교 (2026-11-27 추가)

| 항목 | 초등학교 | 중·고등학교와 다른 점 |
